# Projeto de Portfólio — Origamid

## Descrição

Desenvolvimento de um portfólio pessoal de página única (*one-page*), utilizando HTML5 e CSS3, com o propósito de apresentar projetos, habilidades e informações profissionais, aplicando os conceitos de desenvolvimento web aprendidos no curso da Origamid.

## Seções do Portfólio

- **Experiência:** Apresenta as experiências profissionais e os projetos desenvolvidos (fictício).
- **Formação:** Exibe a formação acadêmica e os cursos realizados.
- **Contato:** Disponibiliza informações e links para facilitar o contato profissional.
